## 📌 Executive Summary

Under the framework of the **Comprehensive Nuclear-Test-Ban Treaty (CTBT)**, the International Monitoring System (IMS) continuously detects seismic disturbances globally. Discriminating clandestine, low-yield underground nuclear explosions (UNEs) from shallow, natural tectonic earthquakes is an existential challenge in nuclear non-proliferation verification.

This repository provides an end-to-end, fully reproducible scientific pipeline implementing:
1. **Source Physics Analysis**: Dissecting the fundamental physical divergence between explosive isotropic dilation ($\Delta V > 0$, double-couple moment $M_0 = 0$) and tectonic fault shear slip (quadrupolar double-couple dislocation).
2. **Track A — Physics-Informed Machine Learning**: Extraction of 18 domain-engineered spectral, ratio, and coda features benchmarked across Regularized Logistic Regression ($L_2$), Linear Discriminant Analysis (LDA), Support Vector Machines (RBF SVM), Random Forest, and XGBoost.
3. **Track B — Deep Representation Learning**: A 4-stage 3-channel 2D Convolutional Neural Network (CNN) trained directly on time-frequency log-mel spectrograms ($Z, N, E$ components) with batch normalization, spatial dropout, and cosine annealing learning rate schedules.
4. **Blind Out-of-Sample Nuclear Test Validation**: Zero-shot blind evaluation on all **6 historic North Korean (DPRK) nuclear tests** (2006–2017) recorded at regional station MDJ (Mudanjiang, China), demonstrating 100% recall.

## 🔬 Scientific Methodology & Theoretical Background

### 1. Source Physics & Diagnostic Signatures
| Phenomenon | Underground Nuclear Explosion (UNE) | Tectonic Earthquake |
| :--- | :--- | :--- |
| **Source Mechanism** | Spherically symmetric compressional shock wave ($\Delta V > 0$, pure isotropic moment tensor). | Shear dislocation along planar fault surface (deviatoric double-couple). |
| **High-Frequency $P/S$ Ratio** | Highly elevated ($P$-wave energy strongly dominates; shear waves only generated by secondary scatter/spall). | Low-to-moderate (shear waves $S_n, L_g$ are efficiently generated directly at fault). |
| **Horizontal Shear Energy ($S_H / S_V$)** | Pronounced shear deficit on transverse horizontal channels ($S_H \approx 0$). | Abundant transverse shear radiation across all azimuths. |
| **Spectral Peak & Centroid** | Blue-shifted: compact source dimension ($r_0 \approx 50\text{--}200\text{ m}$) generates rich high-frequency corner ($f_c \propto r_0^{-1}$). | Red-shifted: extensive fault rupture lengths ($L \approx 1\text{--}50\text{ km}$) enrich lower frequencies ($f < 2\text{ Hz}$). |
| **Coda Decay Rate ($\gamma$)** | Rapid energy dissipation; shallow burial ($h < 1\text{ km}$) traps energy in lossy surface layers. | Prolonged coda reverberations across deep crustal waveguide. |

```
                Explosive Source                          Tectonic Earthquake
          (Pure Isotropic Compression)                  (Double-Couple Shear)

                     ↑ P                                        Fault Plane
                  ↗     ↖                                            /
               ←     ⊕     →                                 ↘  |  ↗
                  ↘     ↙                                       |
                     ↓ P                                     ↗  |  ↘
           (Weak secondary S-wave)                          (Dominant S-wave)
```

## 🚀 Quickstart & Reproducibility Guide

### 1. Environment Installation
Clone the repository and set up a virtual environment:
```bash
git clone https://github.com/RajveerVoraUni/nuclear-testing.git
cd nuclear-testing

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Feature Extraction Pipeline
To regenerate the 18 physical features from pre-processed waveform archives:
```bash
python scripts/extract_features.py
```

### 3. Model Training & Benchmarking (Track A)
Train and evaluate all regularized machine learning classifiers:
```bash
python scripts/train_models.py
```

### 4. Convolutional Neural Network Training (Track B)
Train the 3-channel 2D Spectrogram CNN with Cosine Annealing learning rate schedule:
```bash
python scripts/train_cnn.py
```

### 5. Compiling Documents
To recompile the academic report and presentation slides from source:
```bash
pdflatex -interaction=nonstopmode report.tex
pdflatex -interaction=nonstopmode presentation.tex
```
